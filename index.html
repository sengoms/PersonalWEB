How I approach it

Three design positions I hold, whatever the stack.

Retrieval

Clinical questions are answered from a structured record, a terminology graph and documents together — not from documents alone. Route through the graph first so clinician shorthand expands to everything it means, then resolve every answer to sources that carry provenance. If a system can't show the path it took, it isn't ready for a clinician.

Boundaries

Agents orchestrate; servers guarantee. The model never writes a graph query — typed, parameter-bound templates do, which closes the injection class by construction. Guideline logic lives in CPG-on-FHIR and CQL and runs in code; the model reads the result, it doesn't decide it. Scopes enforce minimum necessary on the request side, and audit is fail-closed.

Evidence

Define the gate before the pilot: task benchmarks, citation precision and recall, a synthetic-conflict patient set, and an adversarial corpus with a zero-leakage target. Evaluation harnesses turn model choice from a vendor conversation into a measurement — and they're what lets a security and compliance team say yes.
